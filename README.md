# SK부동산 · 관악구 부동산 브리핑 대시보드

## 처음 설정 (API 키)
API 키는 저장소에 포함되어 있지 않습니다. 아래처럼 설정 파일을 만들고 각 사이트에서 발급받은 키를 넣으세요.
```bash
cp config.example.json config.json
```
| 항목 | 발급처 |
|---|---|
| `seoulKey` | 서울 열린데이터광장 (data.seoul.go.kr) |
| `rebKey` | 한국부동산원 R-ONE 부동산통계정보 (r-one.co.kr) |
| `dataGoKrKey` | 공공데이터포털 (data.go.kr) — 국토교통부 아파트 매매 실거래가 상세 자료 활용신청 |
| `vworldKey` | 브이월드 공간정보 오픈플랫폼 (vworld.kr) — 허용 도메인에 `localhost` 포함 |

## 실행
- `대시보드실행.command` 더블클릭  →  브라우저에서 http://localhost:8790 이 열립니다.
- 또는 터미널에서 `node server.js` (Node 18 이상, 별도 설치 패키지 없음)
- 처음 실행 시 서울시 실거래 3년치를 내려받느라 30초~1분 걸립니다. 이후에는 캐시(data/cache)로 바로 열립니다(6시간마다 자동 갱신).

## 사용 데이터
| 항목 | 출처 |
|---|---|
| 아파트·오피스텔·빌라 매매 실거래 | 서울시 열린데이터광장 `tbLnOpendataRtmsV` |
| 전세·월세 실거래 | 서울시 열린데이터광장 `tbLnOpendataRentV` |
| 주간/월간 매매·전세·월세 지수, 평균가격 | 한국부동산원 R-ONE Open API |
| 매매·전세 수급지수(서남권·서울, 주간) | 한국부동산원 R-ONE |
| 관악구 월별 아파트 매매 거래량(2006~) | 한국부동산원 R-ONE (아파트매매거래현황) |
| 매입자 거주지(관악구 내/서울 타구/타 시도)·연령대 | 한국부동산원 R-ONE |
| 매매가격 대비 전세가격(전세가율) | 한국부동산원 R-ONE |
| 매수자 개인/법인, 직거래 비율, 계약해제, 등기완료 | 국토교통부 아파트 매매 실거래 상세 (공공데이터포털) |
| 배경지도(기본·백지도·위성) | 브이월드 WMTS (지도 오른쪽 위 버튼으로 전환) |
| 단지 위치(지번 → 좌표) | 브이월드 주소 좌표검색 — 실거래 자료의 지번 사용 |
| 행정동 경계, 지하철·버스·학교·시장·마트·관공서·은행 | OpenStreetMap (Nominatim / Overpass) |

API 키는 `config.json` 에 있습니다(서울시·부동산원·공공데이터포털·브이월드).
- 처음 실행하면 단지 좌표를 브이월드에서 아파트부터 한 건씩 받아 `data/vworld_geo.json` 에 저장합니다(최초 약 25분, 이후 즉시). 화면에서 클릭한 단지는 기다리지 않고 바로 조회됩니다.
- 브이월드는 짧은 시간에 요청이 몰리면 몇 분간 접속을 막습니다(지도 타일 포함). 지도가 안 나오면 3~5분 뒤 새로고침하세요. 계속 실패하면 OpenStreetMap 지도로 자동 전환됩니다.
- 브이월드 키에 허용 도메인 설정이 있다면 `localhost` 가 포함되어 있어야 합니다.
공공데이터포털 서버에 접속이 안 될 때는 '거래 특성' 칸에 "연결 대기"가 표시되고, 10분마다 다시 시도합니다.

## 인쇄
- 오른쪽 위 `🖨 인쇄 / PDF` 버튼 → 인쇄 창에서 프린터 또는 'PDF로 저장' 선택. A4 가로로 맞춰져 있습니다.
- 인쇄 전에 원하는 동·기간·단지를 선택해 두면 그 화면 그대로(지도 포함) 출력되고, 맨 위에 조회 조건과 출력일이 찍힙니다.
- Claude 앱 안의 미리보기 창에서는 인쇄가 막힐 수 있으니 크롬·사파리 등 일반 브라우저에서 사용하세요.

## 수정하는 곳
- **추천매물**: 화면의 `+ 매물 등록` / 카드의 `수정` 버튼 (저장 위치 `data/listings.json`). 메뉴(분류) 이름을 새로 입력하면 탭이 자동으로 생깁니다.
- **개발계획**: `data/development.json` (이름·유형·진행상태·좌표·설명)
- **단지 위치가 틀리거나 '위치 근사'로 나올 때**: `data/seed_coords.json` 에 `"봉천동|단지명": {"lat": 37.48, "lon": 126.95}` 형식으로 추가 후 서버 재시작.
